# policygate-rag

A retrieval study on τ²-bench's `banking_knowledge` domain: how much of the
domain's task failure is a retrieval problem, and how much of it agentic
retrieval recovers, at what cost. The [policygate](../PolicyGate) harness is on
in every arm; only retrieval varies.

**Status: setup.** No experiment has been run, so there are no results here yet.
Numbers appear in this file only after they have been measured, with intervals.

See `CLAUDE.md` for the design, the arms and the budget.
